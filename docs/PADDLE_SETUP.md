# Paddle Billing setup

The credit-purchase UI now uses Paddle Checkout only. No YouCanPay checkout is shown.

## Required Vercel environment variables

Set these for Production (and use sandbox values for Preview while testing):

- `NEXT_PUBLIC_PADDLE_CLIENT_TOKEN`: Paddle client-side token. This is designed to be public in browser code.
- `PADDLE_ENVIRONMENT`: `sandbox` for Paddle sandbox or `production` for live.
- `PADDLE_WEBHOOK_SECRET`: endpoint destination secret generated by Paddle for the webhook below. Keep private.
- `PADDLE_PRICE_ID_BEGINNER`: Paddle price ID for Starter, USD 10 one-time.
- `PADDLE_PRICE_ID_BUILDER`: Paddle price ID for Basic, USD 25 one-time.
- `PADDLE_PRICE_ID_CREATOR`: Paddle price ID for Pro, USD 50 one-time.
- `PADDLE_PRICE_ID_PRO`: Paddle price ID for Business, USD 100 one-time.
- `PADDLE_PRICE_ID_ELITE`: Paddle price ID for Premium, USD 200 one-time.
- `PADDLE_PRICE_ID_ULTIMATE`: Paddle price ID for Elite, USD 500 one-time.

Create one Paddle catalog product for ViralStudio AI Credits (or use an existing approved product) and create the six one-time USD prices above. The configured price amounts must match the prices in `lib/paymentTransactions.js`. The checkout sends the internal transaction ID, user ID, plan ID, and credit quantity as Paddle custom data.

## Webhook

Create a Paddle notification destination pointing to:

`https://viralstudio-ai.com/api/webhooks/paddle`

Subscribe to at least:
- `transaction.completed`
- `transaction.payment_failed`
- `transaction.canceled`

Copy the destination's secret key into `PADDLE_WEBHOOK_SECRET`.

Credits are granted only after a signed `transaction.completed` webhook, with an idempotency check against the credit ledger. The webhook checks the USD subtotal against the internal pack amount before granting credits.

## Before going live

1. Verify the domain and default payment link in Paddle.
2. Test all six price IDs using sandbox credentials and a sandbox webhook destination.
3. Switch the client token, price IDs, environment, and webhook secret to live values only after Paddle approves the account and domain.
